# ATS Resume Analyzer

An AI-powered Applicant Tracking System (ATS) Resume Analyzer that evaluates resumes against job descriptions and provides structured feedback, keyword matching, and improvement suggestions.

## Features

- Resume upload (PDF)
- Job description upload
- Resume parsing
- Keyword matching
- ATS compatibility score
- Missing skills detection
- Candidate summary generation
- PostgreSQL database integration
- Flask backend with REST APIs

## Tech Stack

- Python
- Flask
- PostgreSQL
- HTML/CSS
- Scikit-learn
- Pandas
